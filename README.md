# morning-news-podcast

毎朝6時（JST）に経済ニュース番組「Morning Brief」を自動生成して配信するシステム（v4）。

## 構成

```
/
├─ morning_news.py     # 原稿生成・音声合成・サイトデータ生成
├─ portfolio.json      # ポートフォリオの唯一の正（Single Source of Truth）
├─ docs/               # GitHub Pages 公開ディレクトリ
│   ├─ index.html      # プレーヤー + ポートフォリオ・ダッシュボード
│   ├─ settings.html   # ポートフォリオ編集画面
│   ├─ app.js          # dashboard.json/portfolio.json を fetch して描画 + 編集ロジック
│   ├─ style.css       # 「朝のラジオスタジオ」デザイン
│   ├─ dashboard.json  # 実行毎に生成される表示用データ（価格・損益・テーマ等）
│   ├─ portfolio.json  # ルートの portfolio.json の同期コピー（読み取り用）
│   ├─ podcast.mp3     # 当日の音声
│   └─ script_*.txt    # 生成原稿（直近7日分）
└─ .github/workflows/daily.yml  # 毎朝6時(JST)に実行
```

## ポートフォリオの編集

`portfolio.json` がポートフォリオの唯一の正。編集方法は2つ：

- **方式A（サイトから）**: `settings.html` でファイングレインドPAT（対象リポジトリの Contents: Read/Write のみ）を設定すると、GitHub API 経由で直接コミットされる。トークンはブラウザの localStorage にのみ保存。**この運用はリポジトリがPrivateであることが前提**。
- **方式B（手動）**: PAT未設定時は、設定画面の「保存」でコミット用JSONが表示されるので、手動で `portfolio.json` にコミットする。

`shares: 0` の銘柄（未購入・監視中）は株価取得・原稿・ダッシュボード集計から除外される。`is_fund: true` の投資信託は価格自動取得の対象外。

## 日替わり構成エンジン

マンネリ化防止のため、以下を日付ベースで決定的にローテーションする：

- **曜日テーマ**: 月=ウィークリー・プレビュー / 火=グローバル・フォーカス / 水=マーケット・メカニクス / 木=セクター・ディープダイブ / 金=ウィークリー・ラップアップ / 土=リバランス・レビュー / 日=ロング・ビュー
- **特集コーナー**（7種を7日周期で循環）: 今日の数字 / 保有銘柄スポットライト / 投資用語の基礎 / ヒストリー / ウォッチリスト / クオート / コントラリアン
- **オープニングの語り口**（5種）
- 直近7日分の原稿から頻出フレーズを抽出し、「避けるべき表現」としてプロンプトに渡す

月初第1土曜はリバランス日として、逆指値更新のリマインドを原稿に入れる。

## 価格データの信頼性

- `fetch_price_robust()`: 直近5営業日から最新の有効な終値を採用し、取得日（as_of）と鮮度（stale: 3日超）を必ず付与
- `calc_position()`: 損益率・評価額・損益額に加え、損切り/利確ラインまでの距離を**価格と％の両方**で算出
- 原稿・サイトの全ての価格に as_of を併記。stale データには明示的なバッジ・注記

## 必要なシークレット

- `GEMINI_API_KEY`: 原稿生成（Gemini API）

音声合成は edge-tts（ja-JP-NanamiNeural）。
